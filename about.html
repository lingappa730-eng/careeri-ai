🤖 About This Project

AI Career Recommendation System With Skill-Gap Analysis

What is this project?

Many students are confused about career. They learn random courses from YouTube and waste 6 months. This project solves that problem.

Student enters skills like Python, SQL, Excel. AI matches those skills with 20 careers using TF-IDF + Cosine Similarity, shows Match %, shows Skill Gap (Have vs Missing) and gives 60-Day Roadmap to become job-ready.

How It Works

StepWhat Happens
1. InputUser enters skills
2. AI MatchTF-IDF + Cosine Similarity calculates Match %
3. Skill GapRequired - Have = Missing Skills
4. Roadmap60-Day plan to learn missing skills

Technologies Used

Python, Flask, HTML, CSS, JavaScript, Scikit-Learn (TF-IDF), Machine Learning

Uses

✅ For Students - Choose right career
✅ For Job Seekers - Know what to learn next
✅ For Colleges - Guide students correctly
✅ For Companies - Check candidate fit
