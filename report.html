AI CAREER RECOMMENDATION SYSTEM
WITH SKILL-GAP ANALYSIS

Final Year Project | Python + Flask + Machine Learning



1. Abstract

Students don't know which career suits their skills and what skills they are missing. This system takes user's skills, uses TF-IDF + Cosine Similarity to recommend best career, shows Skill Gap (Have vs Missing), gives 60-Day Roadmap, Learn 100% Plan with Videos + Free Courses, 3 Assignments per skill, Chart Update on completion, and generates a Certificate after 100% completion. It also analyzes Resume (PDF/DOCX) and Job Description (JD) match.

2. Objectives

  • Recommend best career based on skills using Machine Learning
  • Show Skill Gap - What user has vs what is missing
  • Give Roadmap + Learning Resources (YouTube, NPTEL, Great Learning, Coursera)
  • Give Assignments - 3 per skill (Easy, Medium, Project)
  • Update Main Analysis Chart when assignment completed
  • Generate Certificate after 100% completion
  • Resume + JD Analysis

5. How It Works - Algorithm

Step 1: User enters skills - e.g. Python, SQL, Excel, Power BI
Step 2: TF-IDF converts skills + career skills to numbers
Step 3: Cosine Similarity calculates Match % for each career
Step 4: Top career shown + Have vs Missing
Step 5: For Missing Skills - Learn 100% Plan + Assignments shown
Step 6: Tick Assignment → Progress = Start + (Done/Total)*(100-Start) → If Done == Total, Progress = 100% → Certificate Generates
Step 7: Click "Add All Skills" → Skills Box updated → getRecommend() runs again → Chart improves to 100%
